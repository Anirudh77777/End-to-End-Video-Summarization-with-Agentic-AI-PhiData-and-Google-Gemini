# End-to-End Video Summarization App with Agentic AI, PhiData, and Google Gemini

This repository demonstrates a cutting-edge video summarization pipeline leveraging Agentic AI, PhiData, and Google Gemini. The project showcases how AI technologies can be combined to efficiently summarize video content for diverse applications such as media analysis, education, and content management.

---

## 🚀 Features

- **Agentic AI**: Automates key aspects of video analysis, enhancing the accuracy and efficiency of summarization.
- **PhiData Integration**: Provides seamless data handling, storage, and processing for scalable video summarization workflows.
- **Google Gemini**: Leverages advanced large language and vision models for extracting meaningful insights from videos.
- **Customizable Summarization**: Adjustable parameters for varying levels of detail in the summarized output.
- **Scalable Workflow**: Optimized for batch processing of large video datasets.

---

## 🛠️ Tech Stack

- **Programming Languages**: Python
- **Frameworks**: Agentic AI, PhiData SDK
- **AI Models**: Google Gemini (LLMs and Vision Models)
- **Additional Tools**: Pandas, NumPy, OpenCV, Matplotlib
